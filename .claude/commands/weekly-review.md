description: The Monday review, written from three commands. The pipeline, the refix book, the money and the file, then the five things that matter this week.
---

Run these three, in this order, and write the review from what they return. Do not write anything they do not support.

```
npm run mortgage -- pipeline
npm run mortgage -- attention
npm run mortgage -- commissions
```

Then write it in this shape, no more than a page:

1. **The week in one line.** Deals at lenders and their total, settlements booked this week, how many fixed rates expire inside 90 days, and whether any commission is owed or short.
2. **Deals that die this week.** Finance clauses due, pre-approvals expiring, settlements booked. Each with its adviser and the single next action.
3. **The refix book.** Anything lapsed first, then the expiries inside 60 days with no recent contact. Name the dollar value of the book at risk; that is the number that gets these calls made.
4. **The money.** Upfronts not received 30 days after settlement, anything short against the schedule, clawbacks raised. One line each with who owes what.
5. **The file.** Advice records missing at or past submission, and any client with no CDD on a live deal. These are the lines an FMA monitoring visit reads.
6. **Reviews and quiet clients.** Overdue annual reviews with the book value beside them, and anyone with real money on the book that nobody has rung in ninety days.
7. **The five things to do this week.** Pick them yourself from the attention list, weighted by what dies first and what it is worth, and say why each made the list.
8. **One thing to decide.** The single item that needs a person, not a process.

Add `npm run view -- week` and `npm run view -- book` if the operator wants pages to send on. They render the same numbers in the business's brand, and they print.

Numbers come from the commands. If a number is not in the output, it does not go in the review.
