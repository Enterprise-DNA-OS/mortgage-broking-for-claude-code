description: The annual review book, overdue first. The ongoing service the client was promised, and the cheapest retention there is.
---

1. Run `npm run mortgage -- reviews-due`.
2. Overdue first, and beside each one the number that matters: the client's book. A $556,000 client with a review four months overdue is not an admin backlog, it is the trail and the next refinance sitting unattended.
3. Cross-reference the refix book: a review due near a fixed expiry is one call, not two. Say which ones combine.
4. For each overdue review, the action is a booking, not an apology. Draft the note if asked, into `drafts/`, and log the call with `log <client> "..."` when it happens.
5. When one is done: `review done <client> --on=`. The next one schedules itself twelve months out. When a client is taken on mid-cycle: `review schedule <client> --due=`.
6. `npm run docs -- annual-review-summary` renders a review pack per client into `docs-out/`, in the business's brand: their whole lending, rates, expiries and deal history on one page. Take it to the meeting.

The review was promised in the disclosure. Delivering it is a conduct obligation and the best source of top-ups, restructures and referrals the business has. Both things are true; lead with whichever moves the operator.
